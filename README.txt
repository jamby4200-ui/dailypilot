DAILYPILOT v0.2 — ANDROID-FIRST PWA PROTOTYPE

WHAT CHANGED IN V0.2
- Fixed recurring task alarms so daily/weekday/weekly tasks use the current occurrence date.
- Added a 90-second catch-up window when the app wakes or becomes visible shortly after a scheduled alarm. This is not a guarantee for longer suspensions.
- Added Install App support where the browser exposes an install prompt.
- Added Screen Wake Lock control where supported, to keep the screen awake while DailyPilot is visible.
- Added 192px and 512px app icons and improved PWA manifest metadata.
- Updated service-worker cache version so the new shell replaces the old one.

IMPORTANT ALARM LIMITATION
This is still a web app. Its loud alarm is generated by page JavaScript. It cannot guarantee clock-like alarms if the app is closed, the browser process is killed, the device sleeps, or Android suspends the page. Notifications are not equivalent to a native alarm. Do not rely on this version alone for critical appointments.

FREE HOSTING: GITHUB PAGES (RECOMMENDED)
1. Sign in or create a GitHub account at https://github.com/.
2. Create a new public repository named dailypilot (or another name).
3. Upload the CONTENTS of this folder to the repository root: index.html, manifest.webmanifest, sw.js, icons/ and README.txt. Do not upload only the ZIP.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the HTTPS site. The URL usually looks like https://YOUR-USERNAME.github.io/dailypilot/.
7. Open the HTTPS URL in Chrome on your Android phone. Add one test task two minutes ahead and tap Test alarm to grant audio playback.
8. Use the browser menu ⋮ > Install app or Add to Home screen. If the Install app button appears inside DailyPilot, you can use that instead.
9. Allow notifications if desired. For the best web alarm behavior, open DailyPilot, tap Keep screen awake, keep the page in the foreground, and ensure media volume is audible.
10. Test with the screen on, screen off, app backgrounded, and after restarting the phone. Expect web alarms to fail in some closed/background states.

ANDROID INSTALLATION TEST CHECKLIST
- [ ] Site loads over HTTPS.
- [ ] Chrome offers Install app / Add to Home screen.
- [ ] App icon and standalone display work.
- [ ] Test alarm sounds after user taps Test alarm.
- [ ] A daily recurring task alarms again on the next day.
- [ ] Screen Wake Lock button works on supported devices.
- [ ] Verify data is local to each browser/device; this version does not sync devices.

NEXT STEP FOR REAL ALARM RELIABILITY
A native Android version should use Android AlarmManager (preferably exact alarms where permitted), a notification channel, a full-screen alarm notification/activity, reboot rescheduling, and the required exact-alarm permission flow. Android versions and manufacturer battery policies differ, so this requires a real-device test. PWA-only code cannot provide the same guarantee.
